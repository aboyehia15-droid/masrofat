# مصروفات مجمع ابن تيمية — الواجهة

الرابط: https://aboyehia15-droid.github.io/masrofat/

هذا المستودع فيه واجهة البرنامج. كود الخادم (Apps Script) موجود في مستودع goto داخل `masrofat/server`، ومنه يجلب الخادم تحديثاته تلقائياً.

| الملف | ما فيه |
|---|---|
| `index.html` | هيكل الصفحات |
| `styles.css` | الألوان والتنسيق |
| `app.js` | عمل الواجهة: الرفع، القائمة، الكشوف، Excel، الإعدادات |
| `config.js` | رابط الخادم والشعاران الافتراضيان |
